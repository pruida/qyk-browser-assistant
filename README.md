# 启源浏览器助手

这是配合 [启源 AI](https://ai.qykaiwu.cn/) 使用的 Chrome 浏览器扩展。你可以直接在聊天框里描述要做的事情，助手会打开网页、读取当前页面并逐步执行操作。

例如：

- `帮我打开携程，查询明天上海到北京最便宜的机票`
- `在商标网站查询 99145910，并下载 Registration Certificate`
- `打开官网查找最近 10 天最热门的内容，列出来源链接`
- 完成第一次查询后继续说：`只看公务舱`、`改成后天`、`下载 PDF`

> 当前版本：**v0.7.0**。它修复了重复下载问题，并会在插件不是最新版时提醒更新。

## 一、安装前准备

你需要：

- 一台 Windows 或 macOS 电脑；
- Google Chrome 浏览器；
- 能正常打开 [ai.qykaiwu.cn](https://ai.qykaiwu.cn/)；
- 插件压缩包。可从 [GitHub Releases](https://github.com/pruida/qyk-browser-assistant/releases/latest) 下载最新版，也可以使用 [官网下载链接](https://ai.qykaiwu.cn/static/qyk-browser-assistant-v0.7.zip)。

手机 Chrome 暂不支持这种安装方式。

## 二、安装插件（第一次安装）

### 第 1 步：下载并解压

1. 下载 `qyk-browser-assistant-v0.7.zip`。
2. 找到下载的 ZIP 文件。
3. Windows：右键文件，选择“全部解压”。
4. macOS：双击 ZIP 文件即可解压。
5. 打开解压后的文件夹，确认可以直接看到 `manifest.json`、`background.js` 和 `popup.html`。

不要直接选择 ZIP 文件，Chrome 只能加载**解压后的文件夹**。

### 第 2 步：打开扩展管理页

1. 在 Chrome 地址栏输入 `chrome://extensions/`。
2. 按回车键。
3. 打开页面右上角的“开发者模式”。

如果点击网页里的 `chrome://extensions/` 链接没有反应，这是 Chrome 的安全限制，请手动复制到地址栏。

### 第 3 步：加载插件

1. 点击左上角“加载已解压的扩展程序”。
2. 选择刚才解压的文件夹。
3. 页面出现“启源浏览器助手”，并显示版本 `0.7.0`，表示安装成功。
4. 建议点击浏览器右上角拼图图标，把“启源浏览器助手”固定在工具栏。

[观看 28 秒安装教学视频](https://ai.qykaiwu.cn/static/qyk-browser-extension-install-v0.7.mp4)

## 三、第一次使用

1. 安装完成后，打开或刷新 [启源 AI 聊天页面](https://ai.qykaiwu.cn/)。
2. 在聊天框输入一个明确任务，例如：

   ```text
   帮我打开携程，查询明天上海到北京最便宜的机票
   ```

3. 插件会打开一个新的网页标签页，并在聊天界面显示“浏览器助手已接管”。
4. 操作过程中请保留聊天页和目标网页，不要关闭它们。
5. 查询完成后，插件会回到聊天页面并给出结果。
6. 可以在同一会话继续追问，例如：

   ```text
   只看公务舱
   ```

   ```text
   日期改成最近 10 天，按价格从低到高比较
   ```

## 四、怎样描述任务更容易成功

尽量一次说清楚“网站、目标、条件和结果形式”。推荐写法：

```text
在 https://tsdr.uspto.gov/ 查询商标号 99145910，找到 Registration Certificate，
下载 PDF，并把文件名改成“美国商标注册证书+商标名+商标号+类别.pdf”。
```

如果网站需要登录，建议先由你亲自登录，再让助手继续。密码、验证码、身份证、护照、银行卡和支付信息需要由你本人填写。

## 五、更新插件

聊天页会读取最新版本号。如果检测到旧版，会在页面顶部提示“下载最新版”，并暂停新的浏览器任务。

更新方法：

1. 下载最新版 ZIP 并解压。
2. 打开 `chrome://extensions/`。
3. 最稳妥的方式是删除旧版“启源浏览器助手”。
4. 点击“加载已解压的扩展程序”，选择新版文件夹。
5. 确认版本号已经更新。
6. 刷新启源 AI 聊天页面。

插件不会在后台自动下载更新包，只有你点击下载链接后才会下载。

## 六、停止任务

在同一个聊天会话里发送：

```text
停止浏览器操作
```

也可以发送 `取消这个任务`。如果旧版本正在反复下载，请先在 Chrome 下载页面 `chrome://downloads/` 取消下载，然后在扩展管理页删除旧版并安装最新版。

## 七、权限和隐私

安装时 Chrome 会提示插件可以“读取和更改您在所有网站上的数据”，因为插件需要根据你的聊天命令操作不同网站。下载与重命名文件还需要 Chrome 的下载管理权限。

- 只有你从启源 AI 发起浏览器任务时，插件才会执行操作。
- 页面可见文字、可操作元素和当前页面截图可能会发送给 GPT-6，用于判断下一步动作。
- 敏感输入框内容会在插件内屏蔽。
- 插件不会自动填写密码、验证码、证件或支付信息。
- 插件不会自动确认付款、提交订单、转账或删除账户。

更完整的说明见 [隐私与安全说明](PRIVACY.md)。

## 八、常见问题

### 安装时提示“清单文件缺失或不可读取”

通常是选错了文件夹。请进入解压目录，选择那个**里面直接包含 `manifest.json`** 的文件夹。

### 安装后聊天页仍提示未安装

1. 在 `chrome://extensions/` 确认插件开关已经打开。
2. 确认版本是最新版。
3. 刷新 `https://ai.qykaiwu.cn/`。
4. 如果仍无效，关闭聊天标签页后重新打开。

### 插件提示旧版本

Chrome 加载的可能仍是旧文件夹。删除旧插件，再选择新解压的目录重新加载。

### 网页没有继续操作

网站可能正在加载、弹出验证码、要求登录，或者页面内容位于受限制的 iframe 中。切到目标网页查看提示，完成需要本人处理的步骤后，再回聊天继续说“继续”。

### 为什么不能自动付款或提交订单

付款、转账、最终下单等不可逆操作必须由用户本人确认。这是插件的安全边界，不是故障。

### 下载的文件在哪里

默认保存在 Chrome 设置的下载目录中。最稳妥的查看方法是在地址栏打开 `chrome://downloads/`。

### 支持哪些网站

插件不是只为携程编写的，可以操作多数普通 HTTP/HTTPS 网站。但 Chrome 内置页面、Chrome Web Store、验证码、跨域受限 iframe、复杂画布应用以及网站风控页面可能无法自动操作。

## 九、给开发者

```bash
npm test
```

主要文件：

- `content/chat-bridge.js`：连接启源 AI 聊天页与扩展后台。
- `background.js`：保存任务、调用规划接口、管理标签页和下载。
- `content/browser-agent.js`：读取网页并执行单步受控操作。
- `content/ctrip.js`、`lib/task-parser.js`：保留的历史站点增强模块，不是通用流程的入口。

扩展采用 Manifest V3。每次只执行一个模型规划动作，随后重新读取页面；相同页面上的重复下载或重复提交会被拦截。
